# Calm Before The Storm

[![Play Now on Itch.io](https://img.shields.io/badge/PLAY%20NOW-Itch.io-FA5C5C?style=for-the-badge&logo=itch.io&logoColor=white)](https://erfan-khodami.itch.io/CalmBeforeTheStorm)

A tense atmospheric game that explores the quiet moments before dramatic change.

## Game Description
"Calm Before The Storm" immerses players in a beautifully crafted world where tension builds beneath a serene surface. Experience the psychological and environmental shifts that precede major events.

## Key Features
- Atmospheric storytelling
- Dynamic environment that evolves with gameplay
- Psychological tension mechanics
- Stunning visual effects
- Original soundtrack that adapts to gameplay
